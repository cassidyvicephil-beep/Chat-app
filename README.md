# Chat-app
Une application qui doit répondre correctement aux messages que l'on lui envoient, générer des vidéos, surtout des vidéos de fruits comme sur trendstory.io et de les poster directement sur tiktok, une application qui aide pour les études comme Nomad éducation et une application qui peut échanger en voice comme ChatGPT, mode ChatGPT réponse
